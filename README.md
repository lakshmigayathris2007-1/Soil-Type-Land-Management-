# Soil Type and Land Management System

## Overview
The Soil Type and Land Management System is a Spring Boot based web application developed to manage agricultural land information efficiently. The system provides a structured platform for maintaining soil records, land details, crop recommendations, fertilizer information, irrigation methods, farmer data, and weather-related information.

The application supports smart agricultural decision-making by integrating land management and soil analysis into a unified system. It enables users to store, retrieve, update, and analyze agricultural data through RESTful APIs and database integration.

## Features
- Soil type management  
- Land record management  
- Farmer information management  
- Crop recommendation management  
- Fertilizer management  
- Irrigation management  
- Weather data management  
- CRUD operations using REST APIs  
- Database connectivity using JPA and JDBC  
- Layered architecture with modular design  

## Technologies Used

## How to Run
1. Clone the repository:
```bash
git clone https://github.com/your-username/Soil-Type-Land-Management-System.git
```

2. Navigate to project directory:
```bash
cd Soil-Type-Land-Management-System
```

3. Run using Maven:
```bash
mvn spring-boot:run
```

Or using Gradle:
```bash
gradle bootRun
```
