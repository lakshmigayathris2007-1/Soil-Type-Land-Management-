⚙️ REST API Reference

── SOIL ────────────────────────────────────────────────── POST /api/soil Create new soil record GET /api/soil List all soils (optional: ?sortByFertility=true) GET /api/soil/{id} Get soil by ID GET /api/soil/type/{type} Filter by soil type GET /api/soil/{id}/nutrients Nutrient deficiency report GET /api/soil/grouped Soils grouped by type (HashMap) GET /api/soil/stats/by-type JDBC: count by type GET /api/soil/stats/ph JDBC: pH statistics PUT /api/soil/{id} Update soil measurements DELETE /api/soil/{id} Delete soil record ── LAND ────────────────────────────────────────────────── POST /api/land Register land parcel GET /api/land/{id} Get land by ID GET /api/land/survey/{no} Get by survey number GET /api/land/district/{d} Filter by district GET /api/land/by-farmer HashMap: farmerId → lands GET /api/land/stats/by-district JDBC: area by district PUT /api/land/{id} Update land details DELETE /api/land/{id} Delete land record ── CROP ────────────────────────────────────────────────── POST /api/crop Add crop GET /api/crop List all crops GET /api/crop/{id} Get by ID GET /api/crop/categories Unique categories (HashSet) GET /api/crop/sorted Sorted by growth duration (Comparator) PUT /api/crop/{id} Update crop DELETE /api/crop/{id} Delete crop ── FARMER ──────────────────────────────────────────────── POST /api/farmer Register farmer GET /api/farmer List all farmers GET /api/farmer/{id} Get by ID GET /api/farmer/summaries Dashboard summaries (ArrayList + Iterator) GET /api/farmer/count/{st} JDBC: count by state PUT /api/farmer/{id} Update farmer DELETE /api/farmer/{id} Delete farmer ── GENERIC ─────────────────────────────────────────────── DELETE /api/record/{id}?type=SOIL|LAND|CROP|FARMER
